# Week 4 — Gather UX/UI Case Study & Interactive Prototype

**Project:** Gather — local event discovery and community connection  
**Deliverable:** Research-framed case study, reusable visual design system, responsive 16-screen front-end prototype, and developer handoff notes.

## Open the project
Open `index.html` in a modern browser. It is self-contained: no build tools, external packages, API keys, or external assets are required.

## Case study contents
- Problem framing and design opportunity
- Three illustrative proto-personas with needs and quotes
- Illustrative user journey map
- Category-level competitive landscape framework
- Product principles and information architecture
- Visual tokens: forest green, citrus, paper, coral; typography and reusable controls
- Sixteen-screen inventory and interactive prototype
- Handoff and accessibility checklist
- Proposed validation plan and next steps

## The 16 prototype screens
1. Home & discovery
2. Search results
3. Browse categories
4. Filter & sort
5. Event details
6. Host profile
7. Community preview
8. RSVP form
9. RSVP confirmation
10. Saved events
11. My plans
12. Location & directions
13. Notifications
14. Profile
15. Interests & preferences
16. Empty & recovery state

## Working interactions
- Navigate between screens using the prototype sidebar and next/previous controls.
- Search events by keyword and filter by interest or free events.
- Save/unsave events and inspect the saved list.
- Open event details, host information, community preview, and illustrative location information.
- Complete a demo RSVP form to see a confirmation and add the event to My plans.
- Toggle interests and mark notifications as read.
- Select a screen in the screen inventory to view its purpose and primary interaction.

## Design system
- **Forest:** `#245C45`
- **Citrus:** `#D8F36A`
- **Paper:** `#F7F7F2`
- **Coral:** `#ED875D`
- **Typography:** native system sans-serif stack, bold display hierarchy, readable compact labels.
- **Components:** buttons, filter chips, event cards, tags, search fields, forms, navigation, profile cards, confirmation and empty states.
- **Responsive:** desktop case study and prototype, adaptive card grids, compact mobile navigation and stacked forms.

## Research integrity note
This is a concept project. Personas, quotes, competitor observations, and journey-map emotions are illustrative hypotheses for demonstrating the UX process. No user interviews, usability tests, competitor audit, or product analytics are claimed to have been completed. Validate these hypotheses with real participants before treating them as research findings. Metrics are intentionally not fabricated.

## Handoff and accessibility
Use semantic HTML, keyboard focus indicators, labels and accessible names. The next phase should add automated accessibility checks, focus trapping for dialogs, production routing, persistent storage, a real mapping provider, and usability testing across mobile and desktop.
